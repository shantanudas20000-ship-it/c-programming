▶️ How to Run

1. Clone the Repository

git clone https://github.com/your-username/c-programming.git

2. Navigate to the Repository

cd c-programming

3. Compile a Program

Example:

gcc Basics/calculator.c -o calculator

4. Run the Program

./calculator

«On Windows, you can run the compiled program using:

calculator.exe»
